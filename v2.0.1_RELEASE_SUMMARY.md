# Hyro v2.0.1 Release Summary

## Release Information

- **Version**: v2.0.1
- **Release Date**: February 23, 2026
- **Type**: Patch Release
- **Previous Version**: v2.0.0

## Overview

This is a patch release that fixes asset loading issues introduced in v2.0.0 and modernizes authentication views.

## What's Fixed

### 1. Asset Path Resolution
**Problem**: CSS and JS files were not loading due to incorrect manifest path.

**Solution**: Updated `HyroAsset` helper to check the correct manifest location:
- Primary: `public/vendor/hyro/.vite/manifest.json` (new v2.0 location)
- Fallback 1: `public/vendor/hyro/manifest.json` (backward compatibility)
- Fallback 2: `vendor/marufsharia/hyro/dist/.vite/manifest.json` (development)
- Fallback 3: CDN assets (if all else fails)

### 2. Duplicate Alpine.js Loading
**Problem**: Alpine.js was being loaded twice in authentication views.

**Solution**: Removed manual Alpine.js script tags since `@hyroAssets` already includes it.

### 3. Auth Views Modernization
**Problem**: Auth views were using deprecated separate directives.

**Solution**: Updated all auth views to use the new `@hyroAssets` directive:
- `login.blade.php`
- `register.blade.php`
- `two-factor.blade.php`
- `two-factor-recovery.blade.php`
- `passwords/email.blade.php`
- `passwords/reset.blade.php`
