# Hyro Admin Panel

Admin interface and dashboard for Hyro.

## Features

- Admin dashboard
- User management UI
- Role and privilege management
- Settings management
- Plugin management UI
- Notification center
- Profile management
- Livewire components

## Installation

```bash
composer require marufsharia/hyro-admin-panel
```

## Dependencies

- marufsharia/hyro-core ^1.0
- marufsharia/hyro-auth ^1.0
- marufsharia/hyro-plugin ^1.0
- Livewire ^3.7.6
