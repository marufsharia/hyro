# Hyro API

RESTful API layer for Hyro.

## Features

- RESTful API endpoints
- API authentication
- API resources
- Rate limiting
- API versioning
- Token management
- CRUD API controllers

## Installation

```bash
composer require marufsharia/hyro-api
```

## Dependencies

- marufsharia/hyro-core ^1.0
- marufsharia/hyro-auth ^1.0
- Laravel Sanctum ^4.0
