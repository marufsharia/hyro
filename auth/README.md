# Hyro Auth

Authentication and authorization package for Hyro.

## Features

- User authentication
- Two-factor authentication (2FA)
- Password reset
- Token management
- API authentication with Sanctum
- Emergency lockdown commands
- Token synchronization

## Installation

```bash
composer require marufsharia/hyro-auth
```

## Dependencies

- marufsharia/hyro-core ^1.0
- Laravel Sanctum ^4.0
- pragmarx/google2fa ^8.0
