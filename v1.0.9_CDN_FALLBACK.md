# Hyro v1.0.9 - CDN Fallback Release

## 🚀 True Zero-Configuration Experience

This release adds CDN fallbacks for CSS and JavaScript, ensuring the package works immediately after installation without any build steps.

## What's New

### CDN Fallback for CSS

When built assets are not available, the package now automatically loads:

1. **Tailwind CSS v3** from CDN
2. **Hyro alert styles** (if published)
3. **Inline utility styles** for Hyro-specific features

**Before v1.0.9:**
```html
<!-- If manifest not found -->
<!-- Hyro CSS not found. Run: php artisan hyro:publish-assets -->
```

**After v1.0.9:**
```html
<!-- If manifest not found, automatically loads: -->
<script src="https://cdn.tailwindcss.com"></script>
<link rel="stylesheet" href="/vendor/hyro/css/hyro-alert.css">
<style>
    /* Hyro-specific utilities */
    [x-cloak] { display: none !important; }
    .glass { background: rgba(255, 255, 255, 0.05); ... }
    /* Custom scrollbars, etc. */
</style>
```

### CDN Fallback for JavaScript

When built assets are not available, the package now automatically loads:

1. **Alpine.js v3** from CDN
2. **Alpine.js plugins** (collapse, focus, intersect)
3. **Hyro alert JS** (if published)

**Before v1.0.9:**
```html
<!-- If manifest not found -->
<!-- Hyro JS not found. Run: php artisan hyro:publish-assets -->
```

**After v1.0.9:**
```html
<!-- If manifest not found, automatically loads: -->
<script defer src="https://cdn.jsdelivr.net/npm/@alpinejs/collapse@3.x.x/dist/cdn.min.js"></script>
<script defer src="https://cdn.jsdelivr.net/npm/@alpinejs/focus@3.x.x/dist/cdn.min.js"></script>
<script defer src="https://cdn.jsdelivr.net/npm/@alpinejs/intersect@3.x.x/dist/cdn.min.js"></script>
<script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3.x.x/dist/cdn.min.js"></script>
<script src="/vendor/hyro/js/hyro-alert.js"></script>
```

## How It Works

### Smart Asset Loading Strategy

```
┌─────────────────────────────────────────┐
│  @hyroCss directive called              │
└─────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────┐
│  Check: manifest.json exists?           │
└─────────────────────────────────────────┘
         │
         ├─── YES ──► Load built CSS
         │            (hyro-[hash].css)
         │            ✅ Optimized, minified
         │
         └─── NO ───► Load from CDN
                      (Tailwind CSS + utilities)
                      ✅ Works immediately
```

### Priority Order

1. **First choice:** Built assets from manifest (if available)
   - Optimized, minified, versioned
   - Best performance
   
2. **Fallback:** CDN assets
   - Tailwind CSS from cdn.tailwindcss.com
   - Alpine.js from cdn.jsdelivr.net
   - Works immediately, no build required

## Code Changes

### Updated File

**File:** `core/src/Helpers/HyroAsset.php`

**Changes:**
- Updated `css()` method with CDN fallback
- Updated `js()` method with CDN fallback
- Added inline utility styles
- Improved fallback logic

### css() Method

```php
public static function css(): string
{
    $manifest = static::manifest();
    
    // Try to get from manifest
    if (isset($manifest['resources/css/hyro.css'])) {
        $file = $manifest['resources/css/hyro.css']['file'];
        $url = asset('vendor/hyro/' . $file);
        return "<link rel=\"stylesheet\" href=\"{$url}\">";
    }
    
    // Fallback: Load Tailwind CSS from CDN + utilities
    $output = '';
    $output .= '<script src="https://cdn.tailwindcss.com"></script>' . "\n";
    
    if (File::exists(public_path('vendor/hyro/css/hyro-alert.css'))) {
        $output .= '<link rel="stylesheet" href="' . asset('vendor/hyro/css/hyro-alert.css') . '">';
    }
    
    $output .= '<style>
        [x-cloak] { display: none !important; }
        .glass { background: rgba(255, 255, 255, 0.05); ... }
        /* More utilities */
    </style>';
    
    return $output;
}
```

### js() Method

```php
public static function js(): string
{
    $manifest = static::manifest();
    
    // Try to get from manifest
    if (isset($manifest['resources/js/hyro.js'])) {
        $file = $manifest['resources/js/hyro.js']['file'];
        $url = asset('vendor/hyro/' . $file);
        return "<script type=\"module\" src=\"{$url}\"></script>";
    }
    
    // Fallback: Load Alpine.js from CDN
    $output = '';
    $output .= '<script defer src="https://cdn.jsdelivr.net/npm/@alpinejs/collapse@3.x.x/dist/cdn.min.js"></script>' . "\n";
    $output .= '<script defer src="https://cdn.jsdelivr.net/npm/@alpinejs/focus@3.x.x/dist/cdn.min.js"></script>' . "\n";
    $output .= '<script defer src="https://cdn.jsdelivr.net/npm/@alpinejs/intersect@3.x.x/dist/cdn.min.js"></script>' . "\n";
    $output .= '<script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3.x.x/dist/cdn.min.js"></script>' . "\n";
    
    if (File::exists(public_path('vendor/hyro/js/hyro-alert.js'))) {
        $output .= '<script src="' . asset('vendor/hyro/js/hyro-alert.js') . '"></script>';
    }
    
    return $output;
}
```
