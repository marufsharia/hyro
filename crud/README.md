# Hyro CRUD

CRUD generator and auto-scaffolding for Hyro.

## Features

- Automatic CRUD generation
- Model generation
- Migration generation
- Livewire component generation
- View generation
- Route generation
- Permission auto-generation
- Smart route discovery

## Installation

```bash
composer require marufsharia/hyro-crud
```

## Dependencies

- marufsharia/hyro-core ^1.0
- marufsharia/hyro-admin-panel ^1.0

## Usage

```bash
php artisan hyro:make-crud ModelName
```
