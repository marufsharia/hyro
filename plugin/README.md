# Hyro Plugin

Plugin and hook system for extending Hyro functionality.

## Features

- Plugin management
- Plugin activation/deactivation
- Hook system (actions and filters)
- Plugin marketplace integration
- Plugin versioning
- Dependency management

## Installation

```bash
composer require marufsharia/hyro-plugin
```

## Dependencies

- marufsharia/hyro-core ^1.0
