# Hyro v1.0.7 Release Notes

## 🎉 Zero-Configuration Asset Management

This release implements **Approach 1** from the Asset Management Guide with full automation!

## What's New

### ✨ Automatic Asset Publishing

Assets are now **automatically published** when you install the package. No manual steps required!

```bash
# Before v1.0.7
composer require marufsharia/hyro
php artisan vendor:publish --tag=hyro-assets  # Manual step
php artisan migrate

# After v1.0.7
composer require marufsharia/hyro
php artisan migrate
# That's it! Assets are already published ✅
```

### 🎨 New Blade Directive: @hyroImage

Load package images easily:

```blade
<img src="@hyroImage('logo.png')" alt="Logo">
```

Automatically resolves to: `/vendor/hyro/images/logo.png`

### 🚀 Complete Blade Directive Suite

All directives are now available:

- `@hyroCss` - Loads versioned CSS (e.g., `hyro-HPBdpIdl.css`)
- `@hyroJs` - Loads versioned JS (e.g., `hyro-D-y3am57.js`)
- `@hyroAssets` - Loads both CSS and JS
- `@hyroImage('path')` - Loads package images

### 🔧 Improved HyroAsset Helper

**core/src/Helpers/HyroAsset.php:**

```php
class HyroAsset
{
    // Reads manifest.json and returns versioned asset URL
    public static function css(): string
    
    // Reads manifest.json and returns versioned asset URL
    public static function js(): string
    
    // Returns both CSS and JS tags
    public static function tags(): string
    
    // Returns image URL from package assets
    public static function image(string $path): string
    
    // Checks if assets are published
    public static function areAssetsPublished(): bool
}
```

### 📦 Auto-Publishing Logic

**AdminPanelServiceProvider.php:**

```php
public function boot(): void
{
    // Auto-publish assets on package installation/update
    $this->autoPublishAssets();
    
    // ... rest of boot logic
}

private function autoPublishAssets(): void
{
    // Check if assets are already published
    if (File::exists(public_path('vendor/hyro/manifest.json'))) {
        return; // Skip if already published
    }

    // Publish during composer operations
    if ($this->app->runningInConsole()) {
        $this->publishAssetsAutomatically();
    }
}
```

## How It Works

### Asset Flow

```
1. User runs: composer require marufsharia/hyro
   ↓
2. Composer installs package to vendor/
   ↓
3. Laravel discovers AdminPanelServiceProvider
   ↓
4. boot() method calls autoPublishAssets()
   ↓
5. Checks if public/vendor/hyro/manifest.json exists
   ↓
6. If not, copies:
   - vendor/.../public/build/ → public/vendor/hyro/
   - vendor/.../resources/css/ → public/vendor/hyro/css/
   - vendor/.../resources/js/ → public/vendor/hyro/js/
   ↓
7. Assets are ready to use!
```

### Blade Directive Resolution

```
User visits page with @hyroCss
   ↓
Blade compiles to: <?php echo \Marufsharia\Hyro\Core\Helpers\HyroAsset::css(); ?>
   ↓
HyroAsset::css() reads public/vendor/hyro/manifest.json
   ↓
Finds: "resources/css/hyro.css" → "assets/hyro-HPBdpIdl.css"
   ↓
Returns: <link rel="stylesheet" href="/vendor/hyro/assets/hyro-HPBdpIdl.css">
   ↓
Browser loads versioned CSS file
```

## Usage Examples

### In Package Layouts

**admin-panel/resources/views/layouts/app.blade.php:**

```blade
<!DOCTYPE html>
<html lang="{{ str_replace('_', '-', app()->getLocale()) }}">
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>{{ $title ?? 'Hyro Admin' }}</title>

    <!-- Fonts -->
    <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700;800;900&display=swap">

    <!-- Hyro CSS (automatically loads versioned file) -->
    @hyroCss
    
    <!-- Livewire Styles -->
    @livewireStyles
    
    <!-- Additional Styles -->
    @stack('styles')
</head>
<body>
    <!-- Logo using image helper -->
    @if(file_exists(public_path('vendor/hyro/images/logo.png')))
        <img src="@hyroImage('logo.png')" alt="Logo">
    @endif

    <!-- Content -->
    {{ $slot }}

    <!-- Hyro JS (automatically loads versioned file) -->
    @hyroJs
    
    <!-- Livewire Scripts -->
    @livewireScripts
    
    <!-- Additional Scripts -->
    @stack('scripts')
</body>
</html>
```

### In Custom Views

```blade
<!DOCTYPE html>
<html>
<head>
    @hyroCss
</head>
<body>
    <div class="hyro-card">
        <h1>Welcome to Hyro</h1>
    </div>
    
    @hyroJs
</body>
</html>
```

### Loading All Assets at Once

```blade
<head>
    @hyroAssets
    <!-- Outputs both CSS and JS tags -->
</head>
```

## Migration Guide

If you're upgrading from v1.0.6 or earlier:

```bash
# Update package
composer update marufsharia/hyro

# Clear caches
php artisan optimize:clear

# Assets will auto-publish if missing
# Or manually republish:
php artisan hyro:publish-assets --force
```

## Verification

### Check Assets Are Published

```bash
dir public\vendor\hyro
```

Should show:
- `manifest.json`
- `assets/` folder
- `css/` folder
- `js/` folder
- `images/` folder (if package has images)

### Check in Browser

1. Visit: `http://127.0.0.1:8000/hyro/admin/dashboard`
2. View source (Ctrl+U)
3. Look for:

```html
<link rel="stylesheet" href="http://127.0.0.1:8000/vendor/hyro/assets/hyro-HPBdpIdl.css">
<script type="module" src="http://127.0.0.1:8000/vendor/hyro/assets/hyro-D-y3am57.js"></script>
```

4. Check console (F12) - No 404 errors ✅

## Troubleshooting

### Assets Not Auto-Publishing?

```bash
# Manually publish
php artisan hyro:publish-assets --force

# Clear caches
php artisan optimize:clear
```

### Permission Issues?

```bash
# Windows (run as Administrator)
icacls public\vendor /grant Users:F /t

# Linux/Mac
chmod -R 755 public/vendor
```
