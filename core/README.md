# Hyro Core

Foundation package for the Hyro ecosystem. Provides RBAC, ACL, models, contracts, and core services.

## Features

- Role-Based Access Control (RBAC)
- Access Control Lists (ACL)
- User management with roles and privileges
- Audit logging
- User suspension system
- Repository pattern
- Event system
- Cache invalidation
- Authorization services
- Gate registration
- Core helpers and utilities

## Installation

```bash
composer require marufsharia/hyro-core
```

## Dependencies

- Laravel Framework ^12.0
- Laravel Sanctum ^4.0
- Ramsey UUID ^4.0

## Usage

This package is the foundation for all other Hyro packages and provides core functionality.
